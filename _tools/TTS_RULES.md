# TTS 변환 규칙 상세 (sub_to_tts.py)

> 자막(_sub.md)을 TTS 대본(_tts.md)으로 자동 변환할 때 적용되는 모든 규칙.
> 파이프라인: 대본 작성 → spoken_check.py → 수정 → **sub_to_tts.py** → precheck → build_html

---

## 0. 끊어 읽기 — 쉼표·마침표 ★★ 대본 쓸 때부터 지킬 것

변환기가 고쳐 줄 수 없는 항목이다. **대본을 쓰는 단계에서 넣어야 한다.**
TTS는 쉼표에서 숨을 쉬고 마침표에서 문장을 닫는다. 쉼표가 없으면 한 호흡에 몰아쳐 읽고, 엉뚱한 데 있으면 뜻이 잘려 들린다.

### 0-1. 쉼표를 반드시 넣는 자리 (한국어 휴지 위치)

| 자리 | 예 |
|------|-----|
| 연결어미 뒤 (~고 / ~며 / ~지만 / ~는데 / ~어서 / ~니까 / ~더니) | `외국인이 4조 원을 던졌고, 개인이 그걸 다 받아냈습니다.` |
| 조건절 뒤 (~하면 / ~한다면 / ~할 경우) | `22만 원을 지키면, 매수세가 남아 있다고 볼 수 있습니다.` |
| 접속부사 뒤 (근데 / 그래서 / 그러니까 / 다만 / 반대로 / 오히려) | `반대로, 이 자리를 이탈하면 얘기가 달라집니다.` |
| 긴 주어부 뒤 (15자 초과) | `어제 저점에서 들어온 반등 자금이, 오늘도 남아 있느냐가 핵심입니다.` |
| 나열 | `외국인, 기관, 개인` / `첫째, 둘째, 셋째` |
| 부름말 뒤 | `여러분, 지금부터 정신 똑바로 차리세요.` |
| 삽입구 앞뒤 | `오늘 종가는, 장중 저가 부근인데, 이게 중요합니다.` |
| 숫자 뒤 해석이 붙을 때 | `13.39 퍼센트 급락했고, 거래량은 4036만 주가 터졌어요.` |
| 강조 도입어 뒤 | `자, 그럼 차트부터 보시면요.` |

### 0-2. 쉼표 금지 자리

| 금지 | 이유 |
|------|------|
| 조사 앞 (`삼성전자, 는`) | 단어가 두 동강 나서 들린다 |
| 관형어–피수식어 사이 (`무너진, 지지선`) | 뜻이 끊긴다 |
| 20자 이하 문장 안 | 뚝뚝 끊겨 답답하다 |
| 쉼표 연속 (`,,`) | 어색하게 길게 멈춘다 |
| 숫자 안 (`4,036만 주`) | 쉼표를 진짜 쉼표로 읽는다 → §3-11 참조 |

### 0-3. 쉼표 밀도

| 문장 길이 | 쉼표 |
|-----------|------|
| 20자 이하 | 넣지 않는다 |
| 40자 초과 | 최소 1개 |
| 70자 초과 | 최소 2개 |
| 4개 초과 | 과다 — 문장을 쪼갠다 |

### 0-4. 마침표·물음표

- 모든 문장 끝에 마침표. 없으면 다음 문장과 이어 읽는다.
- 문장 중간 마침표 금지.
- 반문형은 **물음표 필수** (`이해되시죠?`). 마침표를 찍으면 끝을 올려 읽지 않아 밋밋해진다.
- 느낌표 금지 — 과장되게 소리친다.
- 말줄임표(`…` `...`) 금지 — 읽지 못하고 멈추거나 점을 세어 읽는다.

## 1. 파트 라벨 제거

자막의 블록 구분 라벨(`<후킹>`, `<통합 분석>`, `[인사]` 등)을 TTS에서 제거한다.

```
<통합 분석>    →  (삭제)
[인사]         →  (삭제)
〈대응〉       →  (삭제)
```

- 정규식: `^\s*[<〈\[].{1,16}?[>〉\]]\s*$` 줄 단위 매칭 → 해당 줄 삭제

## 3. 숫자 → 한글 변환

### 3-1. 전화번호

전화번호는 각 자릿수를 개별 한글 발음으로 변환한다.

```
010-5445-1634  →  공일공 오사사오 일육삼사
```

- 숫자별: 0=공, 1=일, 2=이, 3=삼, 4=사, 5=오, 6=육, 7=칠, 8=팔, 9=구

### 3-2. 날짜 (월/일)

월은 특수 읽기(6월=유월, 10월=시월), 일은 한자어.

```
7월 28일  →  칠월 이십팔일
6월      →  유월
10월     →  시월
```

### 3-3. 혼합 금액 표기 (아라비아+한글 단위)

아라비아 숫자와 한글 단위가 섞인 금액을 하나의 수로 합쳐 변환한다. 내림차순이 아니면 건드리지 않는다.

```
6만 8천   →  육만팔천
1천 5백   →  천오백
9만 2천   →  구만이천
```

### 3-4. 단일 천/백/십

```
1천  →  천     (일천 X)
8천  →  팔천
3백  →  삼백
```

### 3-5. 조/억/만 단위

```
1만   →  만     (일만 X)
3억   →  삼억
1조   →  일조   (일조는 유지)
45억  →  사십오억
```

### 3-6. 틸드 범위 (X~Y단위)

```
3~5%       →  삼에서 오퍼센트
200~250원  →  이백에서 이백오십원
```

### 3-7. 소수점 → '쩜'

소수점은 '점'이 아니라 **'쩜'**으로 읽는다. 공백 없이 붙인다.

```
3.8%   →  삼쩜팔퍼센트
5.5배  →  오쩜오배
0.7%   →  영쩜칠퍼센트
```

### 3-8. X.5배 → 배 반

```
1.5배  →  일배 반    (한배 반 X — 밸류 배수는 한자어)
2.5배  →  두배 반
```

### 3-9. 배수 (N배)

| 범위 | 읽기 | 예시 |
|------|------|------|
| 1배 | **일배** (한배 X) | PBR 1배 → 피비알 일배 |
| 2~30배 | 순우리말 | 3배→세배, 10배→열배, 25배→스물다섯배 |
| 31배~ | 한자어 | 33배→삼십삼배 |

- 숫자+배는 무조건 붙여쓴다 (사십구배, 육십이배)
- **10배(열배)는 TTS에서 '열빼'로 경음화** (자막은 '열 배' 유지)

### 3-10. 시각/시간

시(時)는 순우리말, 분(分)은 한자어 유지.

```
2시     →  두 시
3시간   →  세 시간
10시    →  열 시
```

### 3-11. 일반 단위 (정수+단위)

숫자 뒤 단위는 전부 **붙여쓴다** (공백 없음).

```
220,000원  →  이십이만원
52주       →  오십이주
3분기      →  삼분기
136%       →  백삼십육퍼센트
```

### 3-12. 남은 맨숫자

위 규칙에 해당하지 않는 남은 숫자는 한자어로 변환.

```
717  →  칠백십칠
```

## 4. 숫자+단위 붙여쓰기 후처리

### 4-1. 무조건 붙이는 단위

**퍼센트, 개월**은 항상 앞 공백 제거.

```
삼십 퍼센트  →  삼십퍼센트
여섯 개월    →  여섯개월
```

### 4-2. 수사 뒤에서만 붙이는 단위

**원, 배, 주, 명, 년, 곳, 번, 위, 차, 개, 척, 건, 대, 달러**는 수사(만·억·조·천·백·십 + 두·세·네·다섯~아흔) 바로 뒤에서만 붙인다.

이유: '거대한 배(선박)', '살 때 달러를(명사)' 같은 단어 충돌 방지.

```
삼백 원    →  삼백원     (수사 뒤 → 붙임)
열 배      →  열배       (수사 뒤 → 붙임)
백 달러    →  백달러     (수사 뒤 → 붙임)
살 때 달러를 → 살 때 달러를  (명사 → 공백 유지)
거대한 배   → 거대한 배     (명사 → 공백 유지)
```

### 4-3. 큰 수 붙여쓰기 (만·억·조 뒤)

한글로 직접 쓴 큰 수에서 만·억·조 뒤의 공백을 제거한다.

```
만 칠천원    →  만칠천원
만 오백원    →  만오백원
억 오천만원  →  억오천만원
```

- 2회 적용해 '억 오천 만'류도 흡수
- **명사+조사 '만' 보호**: '기회만 사라질'의 '만'은 건드리지 않음 (앞이 숫자 문맥일 때만 작동)

### 4-4. 경음화 특수 규칙

| 자막 | TTS | 비고 |
|------|-----|------|
| 열배 | 열빼 | 10배 경음화 |
| 콩고물 | 콩꼬물 | 경음화 |

## 5. 된소리(경음화) 처리 — 가격어

가격 관련 단어의 끝 '가'를 '까'로 경음화한다.

### 경음화 대상

| 자막 | TTS |
|------|-----|
| 현재가 | 현재까 |
| 목표가 | 목표까 |
| 신고가 | 신고까 |
| 평단가 | 평단까 |
| 추천가 | 추천까 |
| 종가 | 종까 |
| 저가 | 저까 |
| 고가 | 고까 |
| 손절가 | 손절까 |

### 경음화 예외 (보호 목록)

아래 단어는 경음화하면 안 된다 (명사+조사 '가' 또는 내부 '고가' 오매칭 방지):

| 단어 | 이유 |
|------|------|
| 현재가격 | '현재까격' 방지 |
| 시가총액 | 공시가/조사 오판 |
| 최종가 | 조사 오판 |
| 순매수가 | 순매수(행위)+가(조사) |
| 순매도가 | 순매도(행위)+가(조사) |
| 공매도가 | 공매도(행위)+가(조사) |
| 잔고 | '잔고가'→'잔고까' 방지 |
| 광고, 참고, 보고, 재고, 창고 | 'X고가'→'X고까' 방지 |
| 사고, 중고, 경고, 예고, 충고 | 'X고가'→'X고까' 방지 |

### 추가 규칙

- **매수가는 제외**: '외국인 매수가 계속 이어지면서'의 매수가=매수(행위)+가(조사). v15.77로 실행 타점(매수가 숫자)은 문자로 넘기므로 대본 본문에 거의 없음
- **'X가까지' 보호**: '종가까지'가 '종까까지'로 오변환되지 않도록, '까지' 앞에서는 변환하지 않음

## 6. 구어체 검수 (spoken_check.py)

sub_to_tts 변환 **전에** 돌리는 보고서투 탐지 도구. FAIL/PASS가 아닌 '제안' 레벨.

### 6-1. 보고서투 단어 → 구어체 교체

| 보고서투 | 구어체 대체 |
|----------|-------------|
| 일중 (공매도/거래) | 오늘 하루 |
| 사수 | 지켜줬고요 |
| 동반 하락/상승 | ~하면서 같이 밀렸다/올랐다 |
| 반쪽 나다 | 반토막 나다 |
| 선명해지다 | 확실해요 / 보이죠 |
| 뒤집어서 확인 | 반대로 보면 / 삭제 |
| 소진 | 다 나왔다 / 빠졌다 |
| 분기점 | 갈리는 자리 / 갈림길 |
| 안착 | 자리를 잡다 / 올라서다 |
| 변곡 | 방향이 바뀌는 / 꺾이는 |
| 부각 | 눈에 띄다 / 드러나다 |
| 따라서 | 그래서 / 그러니까 |
| 종합하면 | 정리하면요 / 바로 결론부터 |
| ~인 셈이에요 | ~라는 거예요 |
| 뒷받침 | 맞아떨어지다 / 같은 말을 하다 |
| 촉발 | 시작하게 한 / 원인이 된 |
| 괴리 | 차이 / 격차 |
| 위험 회피 | 공포 매도 / 겁먹고 던지는 |
| 여지 | ~할 수 있다 / 가능성 |
| 뚜렷한 | 확실한 / 눈에 보이는 |
| 수렴 | 따라 내려가는 / 맞춰가는 |
| 오독 | 잘못 읽는 거예요 |
| 유인 | ~해야 하는 상황 |
| 헤지 | **헷지** (표기 통일) |
| 봉 | **캔들** (표기 통일) |

### 6-2. 문장 구조 검사

| 검사 항목 | 설명 | 권고 |
|-----------|------|------|
| 퍼센트 과다 | 한 문단에 %가 3개 이상 | 핵심 1~2개만, 나머지는 해석으로 |
| 숫자 4연속 | 숫자 포함 문장이 4개 연속 | 숫자 사이에 해석 끼우기 |
| 명사형 나열 | 'X는 Y고, Z는 W다' 보고서 압축 | 풀어서 구어체로 |
| 어미 4연속 반복 | 같은 종결어미(~요/~습니다) 4문장 연속 | 다른 어미로 섞기 |
| 무생물 주어 | '차트가 말해준다', '숫자가 증명한다' | '차트를 보면요' 사람 주어로 |

## 7. 대본 작성 시 TTS 관련 주의사항

### 7-1. 가격은 아라비아 숫자로 표기

자막에 가격을 아라비아 숫자로 쓰면 sub_to_tts가 정상 변환한다. 한글로 '만 칠천원'이라 쓰면 띄어쓰기 문제가 생길 수 있으므로 `17,000원`으로 쓸 것.

### 7-2. 한자(漢字) 금지

'중국發 공급과잉' 같은 한자 표기 금지. 반드시 한글로 '중국발'로 표기.

### 7-3. 지표명은 영문으로 쓸 것

RSI, PER, PBR 등은 자막에 영문으로 표기하면 sub_to_tts가 자동으로 '알에스아이', '피이알', '피비알'로 변환한다.

### 7-4. 원달러 환율

'원달러 환율'은 합성어로 정상 처리된다 (건드리지 않음).

## 8. 변환 순서 (convert 함수)

```
1. 파트 라벨 줄 제거
2. 영문 → 한글 발음 (convert_english)
3. 숫자 → 한글 (convert_numbers)
   3-1. 전화번호
   3-2. 날짜 (월/일)
   3-3. 혼합 금액 (6만 8천 → 합산)
   3-4. 단일 천/백/십
   3-5. 조/억/만 단위
   3-6. 틸드 범위
   3-7. X.5배 → 배 반
   3-8. 소수점 + 단위 (쩜)
   3-9. 배수 (N배)
   3-10. 시각/시간
   3-11. 일반 단위
   3-12. 퍼센트 기호
   3-13. 남은 맨숫자
   3-14. 붙여쓰기 후처리
   3-15. 큰 수 붙여쓰기
   3-16. 경음화 (열빼, 콩꼬물)
4. 된소리 처리 (apply_doensori)
5. 빈 줄 정리
```

| 항목 | 설명 | 정상값 |
|------|------|--------|
